Privacy Policy

Last updated: 1 November 2026

hermes-vps is a personal automation tool used only by its owner, Razib Hassan. It has no other users.

Data accessed

The tool uses the Google Drive API with the drive.file scope only. It can access only the files it creates in the owner's Google Drive. It cannot see or read any other files.

How data is used

The tool creates and updates documents containing research notes for the owner's weekly column. No other use is made of the data.

Storage and sharing

Access credentials are stored on the owner's private server. No data is sold, shared with, or transferred to any third party.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from https://myaccount.google.com/permissions
